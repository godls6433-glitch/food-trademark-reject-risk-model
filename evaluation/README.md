# 세 모델 비교 (2026-10-12, 10-13 보완)

해인 RF, 예환님 XGB, 가은님 XGB의 예측값 파일을 같은 라벨(features_final_v8.csv의 registered, 257,400행, 거절률 23.56%)로 다시 계산했습니다. 세 파일 모두 순번 순서·출원번호·fold가 라벨과 정확히 일치하고 결측도 없어서, 세 모델을 같은 행과 같은 fold(같은 출원인+같은 상표명 묶음)로 비교할 수 있었습니다.

## 1. 요약

- 교차검증 점수는 예환님 모델이 가장 높았습니다(ROC-AUC 0.725). 다만 해인 모델과의 차이(+0.031) 중 상당 부분은 단어별 거절률 변수와 출원인 경험 변수에서 나온 것으로 보입니다. 단어별 거절률은 계산 방식에 따라 대상 상표보다 나중에 출원된 상표의 결과가 함께 들어갈 수 있고, 출원인 경험은 점검기 입력(상표명·지정상품·로고, 출원인은 선택)만으로는 계산하기 어렵습니다.
- 가은님 모델은 팀 규칙을 충실히 따랐고 확률 보정 방식이 특히 깔끔했지만, 이번 데이터에서는 점수가 가장 낮게 나왔습니다(0.654).
- 예환님 모델의 단어별 거절률은 좋은 아이디어였습니다. **"먼저 출원된 상표만"으로 계산해 해인 변수에 더하면 ROC-AUC가 약 +0.010 오릅니다**(4장).
- 이후 세 분 모두 2022년까지로 학습해 2023~2024년을 예측하는 방식으로 다시 비교했습니다(8장). 그 결과를 바탕으로 한 **최종 추천은 해인 RF + 단어별 거절률**입니다.

## 2. 지표 (5-fold 예측값 전체, 거절 = 1)

| 모델 | ROC-AUC | PR-AUC | Brier | fold별 ROC-AUC | 하위 10% → 상위 10% 실제 거절률 |
|---|---|---|---|---|---|
| 해인 RF | 0.694 | 0.430 | 0.163 | 0.694 ± 0.004 | 7.0% → 53.0% |
| 예환님 XGB | **0.725** | **0.466** | **0.157** | 0.725 ± 0.002 | 4.2% → 56.0% |
| 가은님 XGB | 0.654 | 0.374 | 0.170 | 0.654 ± 0.002 | 10.2% → 45.6% |

- 각자 설명서에 적은 숫자와 소수 셋째 자리까지 모두 같게 재현됐습니다.
- 차이의 95% 구간(짝지은 부트스트랩 200회): 예환 − 해인 +0.031 [0.028, 0.033], 가은 − 해인 −0.040 [−0.042, −0.037]. 두 차이 모두 우연으로 보기는 어렵습니다.
- 확률 보정은 세 모델 모두 양호합니다(예측 10구간별 예측 평균과 실제 거절률 차이 최대 해인 1.1%p, 예환·가은 0.6%p).
- 세 모델 예측의 순위 상관은 0.51~0.61로, 서로 꽤 다른 신호를 활용하고 있습니다.

## 4. 예환님 모델 점수 차이의 요인 분석

예환님의 변수 파일은 없어서, 해인 28개 변수에 예환님 방식의 변수를 하나씩 더해 같은 fold로 다시 학습해 보았습니다(HistGradientBoosting, 같은 설정; 해인 28개만으로 0.697).

| 추가한 것 | ROC-AUC | 증가 |
|---|---|---|
| 없음 (해인 28개) | 0.697 | — |
| + 류 개수(n_cls) | 0.697 | 0.000 |
| + 출원인 경험(같은 그룹의 이전 출원 수, 같은 날 출원 수; 라벨 안에서만 센 근사) | 0.702 | +0.005 |
| + 단어(2글자 조각)별 거절률, fold 방식(예환님 방식과 같이 학습 fold 전체 사용) | 0.715 | +0.019 |
| + 단어별 거절률, 먼저 출원된 상표만 | 0.707 | +0.010 |

- 단어별 거절률의 기여가 가장 컸습니다. fold 방식으로 계산하면 대상 상표보다 나중에 출원된 상표의 결과도 함께 반영되는데, 팀 공통 규칙의 "라벨 상표의 출원일 이후 정보는 변수에 쓰지 않는다"와 맞추려면 먼저 출원된 상표만으로 계산하는 편이 안전합니다. 해인 모델에서도 비슷한 경우(단어 희소성)를 같은 방식으로 고친 적이 있습니다. 먼저 출원된 상표만 쓰면 증가분은 약 절반이 됩니다.
- 출원인 경험은 근사치로 +0.005였습니다. 예환님 모델은 이전 등록 수, 같은 이름 이전 등록 등 더 다양한 경험 변수를 쓰고 있어 실제 기여는 이보다 클 수 있습니다(추정). 출원 경험 11건 이상 그룹에서 예환님 모델의 ROC-AUC가 0.799로 특히 높았습니다(해인 0.722, 가은 0.662).
- 첫 출원 그룹(140,565건)에서도 예환님 모델이 0.693으로 해인 0.671보다 높았습니다. 이 차이는 주로 단어별 거절률 덕분으로 보입니다(추정).
- 하이퍼파라미터 튜닝에 fold 2를 검증용으로 쓰셨는데, fold 2는 다른 회차의 시험 fold이기도 합니다. 설정 간 차이가 0.005 이내라 결과에는 거의 영향이 없을 것으로 보이고, 기록 차원에서 적어 둡니다.

## 5. 가은님 모델 점수에 영향을 준 요인 (추정 포함)

- 본인 상표가 비교 대상에 포함되어 있어, 같은 출원인이 비슷한 이름을 여러 번 출원한 경우 위험이 다소 높게 나오는 경향이 있습니다. 출원 경험 11건 이상 그룹의 실제 거절률은 14.6%인데 가은님 모델의 평균 예측은 22.0%였습니다(해인 15.6%, 예환 14.8%).
- 유사군코드 대신 류 기준으로 비교하고, 선행 상표를 문자 조각 검색 상위 5개 중심으로 보는 방식이라 일부 유사 상표가 빠질 수 있습니다(설명서에도 이 점이 적혀 있습니다).
- 출원인 경험이나 미래 정보를 쓰지 않았고, 시험 fold 밖에서 중첩 방식으로 확률을 보정한 점은 세 모델 중 가장 깔끔했습니다. class_count(n_class)는 위 실험상 점수에 거의 영향을 주지 않았습니다.

## 7. 새 데이터 기준 시험 (2026-10-12 추가)

2017~2022년 출원(191,810건)으로 학습하고 2023~2024년 출원(65,590건, 거절률 20.2%)을 처음 보는 데이터로 예측했습니다. 모델은 해인 RF 설정 그대로(300그루, leaf 20, balanced, 학습 데이터 20%로 isotonic 보정)이고, 시험 행의 단어별 거절률은 2022년까지의 학습 데이터로만 계산했습니다. 코드: timesplit.py, 결과: timesplit_results.csv

| 변수 | ROC-AUC | PR-AUC | Brier |
|---|---|---|---|
| 해인 28개 | 0.713 | 0.407 | 0.146 |
| + 단어별 거절률 (학습 행을 무작위 fold로 계산) | 0.722 | 0.420 | 0.145 |
| + 단어별 거절률 (학습 행도 먼저 출원된 것만) | 0.723 | 0.421 | 0.144 |
| + 출원인 경험 (이전 출원 수, 같은 날 출원 수) | 0.713 | 0.405 | 0.146 |
| + 단어별 거절률(먼저 출원만) + 출원인 경험 | 0.723 | 0.421 | 0.144 |

- 단어별 거절률은 새 데이터에서도 +0.010의 효과가 유지됩니다. 무작위 fold 교차검증에서의 +0.019 중 약 절반은 나중 출원 정보가 반영된 몫이고, 나머지 절반은 새 데이터에서도 유효한 정보로 보입니다.
- 출원인 경험(근사 버전)은 새 데이터에서는 뚜렷한 효과가 없었습니다.
- 참고로 기존 제출 예측값을 2023~2024년 행만 잘라 보면 예환 0.746 / 해인 0.718 / 가은 0.676입니다. 다만 이 값은 무작위 fold라 2023~2024년 상표도 학습에 들어간 결과여서, 새 데이터 성적과는 성격이 다릅니다.

## 8. 네 모델 새 데이터 비교 (2026-10-13 추가)

## 9. 해인 모델 세 가지 비교 (2026-10-13 추가)

같은 28개 변수에서 출발해 세 모델을 만들고, 5-fold 교차검증(라벨 fold 그대로)과 시간 분할(2022년까지 학습, 2023~2024년 시험) 두 방식으로 계산했습니다. 단어별 거절률(2글자 조각별 max·mean·min·개수, 4개)은 각 상표보다 먼저 출원된 상표만으로 계산했고(같은 날 제외), 시간 분할의 시험 행은 2022년까지의 데이터만 썼습니다. 세 모델 모두 학습 데이터 80%로 학습하고 20%로 isotonic 보정을 했습니다.
