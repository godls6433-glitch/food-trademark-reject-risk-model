# 해인 RF 수정 이력

해인 RF를 만들면서 무엇을 바꿨고 왜 바꿨는지 정리했습니다. 팀 전체 흐름은 [docs/process.md](../../docs/process.md)에 있습니다. 항목마다 **문제 → 판단 → 결과** 순서이고, ROC-AUC는 따로 적지 않으면 랜덤포레스트 5-fold 기준입니다.

## 전체 흐름

| 단계 | 핵심 판단 | 5-fold | 2023~24 |
|---|---|---|---|
| 비교 기준 C (유사군코드 겹침) | 실제 심사 방식대로 비교 (A-4) | 0.648 | |
| 출원인 경험 → 본인 상표 유사도 | 점수보다 심사 과정에 맞는 변수, 시점 안전 (B-5, B-6) | 0.678 | |
| 다른 류 같은 유사군코드 추가 | 심사기준 원문 근거 (A-5) | 0.679 | |
| 영문 설명어, 지정상품 관계 | 틀린 사례 분석에서 찾은 구멍 (B-9, B-11) | 0.682 | |
| 결합상표 단어별 비교 | 분리관찰, 누수 제거 (B-12) | 0.692 | |
| 주요부 기준 통일 | 설명어 겹침으로 부풀려진 유사도 제거 (B-13) | 0.691 | |
| 출원인 판별 개선 | 같은 출원인을 정확히 빼기 (A-8) | 0.694 | 0.713 |
| 단어별 거절률 (먼저 출원만) | 팀원 아이디어를 누수 없이 가져옴 (B-15, C-10) | **0.704** | **0.723** |

## A. 데이터

- **A-1 수집 기준을 출원일로 (10/4)**: 등록일 기준으로 받으면 2016년 이전 출원·2017년 이후 등록 상표가 빠진다. 비교 대상이 "먼저 출원된 상표"이므로 모든 데이터를 출원일 기준으로 받아 빈틈을 없앴다.
- **A-2 소멸 상표는 등록일 + 10년 안만 (10/6)**: 소멸일 컬럼이 없어 존속기간 10년으로 근사했다.
- **A-3 학습 라벨 범위 (10/6)**: 결과가 확정된 2017~2024 출원만 정답으로 쓴다. 출원 중·포기·취하·무효·공존동의(당사자 합의라 심사 기준이 아님)·최근 3개월 거절결정 386건은 빼고, 2025~2026 출원은 비교 대상으로만 쓴다. → 257,400건, 거절률 23.56%.
- **A-4 비교 기준 3가지 (10/9)**: 같은 류만 0.644 / 4개 류 통합 0.640 / 유사군코드 겹침 0.648. 가장 높고 「유사상품 심사기준」 제5조(류와 관계없이 유사군코드 기준)와도 맞는 C로 확정했다.
- **A-5 다른 류의 같은 유사군코드 추가 (10/10)**: 기준 C라면 다른 류도 넣어야 한다. 식품류와 겹치는 코드 23개를 가진 5·31·33·1류를 추가 수집해 비교 풀을 50만 → 75만 건(750,680건)으로 늘렸다. 0.678 → 0.679.
- **A-6 35류 판매업 (10/10, 채택 안 함)**: 별도 변수로 넣어 봤지만 효과가 없었고, 심사기준 제7조②(상품과 서비스업은 원칙적으로 비유사)와도 맞아 뺐다.
- **A-7 라벨 쪽 코드는 식품류만 (10/10)**: 결과를 식품 4개 류 기준으로 볼 것이므로 다른 류를 함께 낸 상표도 식품 코드로만 비교한다. 다른 류를 함께 낸 11.7%는 라벨 잡음 가능성으로 한계에 적었다.
- **A-8 본인·계열사 판별 개선 (10/11)**: 이름이 같은 타인 상표가 있는데도 거절률이 28.8%뿐이었다. 들여다보니 계열사·영문 명의·권리 이전으로 같은 회사가 "타인"으로 잡힌 경우가 많았다. 판별 규칙 5개에 "같은 상표 보유" 조건과 그룹 최대 20곳 제한을 붙였다(조건 없이 묶으면 대기업 3만 곳이 한 그룹이 됨). 0.691 → 0.694.

## B. 변수

- **B-1 지정 류 개수 (10/6, 채택 안 함)**: 류를 많이 낼수록 거절률이 낮았지만 큰 회사 효과에 따른 착시다. 넣으면 "류를 많이 넣으면 안전하다"는 잘못된 결론이 나온다.
- **B-2 상품 단어 목록 v2 (10/9)**: 형태소 조각("유지", "수유")이 상품명으로 잡혀 과하게 지워졌다. 실제 지정상품으로 10번 이상 쓰인 단어만 남기고 트렌드 상품명은 직접 추가했다.
- **B-3 지명 사전 v2 (10/9)**: 심사관이 "수유"를 지리적 명칭으로 판단한 사례를 보고 동·읍·면 이름을 추가했다(5,276개). 지명이 들어간 글자상표의 거절률은 40.4%(미포함 26.8%).
- **B-4 주요부 유사도 (10/9)**: 심사처럼 식별력 없는 부분을 뗀 주요부끼리 비교하는 변수를 추가했다. 유사 사유 거절 구분력 0.50 → 0.578.
- **B-5 출원인 경험 → 본인 상표 유사도 (10/10)**: 출원 경험 변수를 넣으면 크게 올랐지만(0.652 → 0.698) 상표 등록 과정과 관계가 없고 점검기 입력으로 계산할 수 없다. 원래 목적인 "본인 상표 빼기"에 맞게 본인 선행상표 유사도로 바꿨다. 0.648 → 0.684. 나중에 2023~24 시간 분할에서도 경험 변수 효과가 0이어서 이 판단을 다시 확인했다.
- **B-6 본인 상표 유사도의 누수 차단 (10/10)**: 심사 중이던 본인 상표가 나중에 등록됐다는 미래 정보가 섞였다. 라벨 출원일 전에 이미 등록된 본인 상표만 쓰도록 바꿨다. 0.684 → 0.678, 점수가 내려가도 시점이 안전한 쪽을 택했다.
- **B-7 겹치는 변수 통합과 버그 수정 (10/10)**: 거의 같은 정보를 담은 변수를 하나로 합치고, 형 변환 실수로 0이던 2·3위 유사도를 고쳤다.
- **B-8 관념 유사 (10/10, 채택 안 함)**: 한영 사전으로 "해 ↔ SUN"을 잡으려 했지만 +0.0005. 사전 품질 한계로 보고 한계에 적었다.
- **B-9 영문 설명어 사전 (10/10~11)**: 크게 틀린 사례를 비교해 보니, 식별력 사유로 거절된 영문 상표의 96%가 설명어 비중 0이었다(OUR Bakery 등). 심사기준의 영문 상품명·품질어로 사전을 만들었다. 0.679 → 0.682.
- **B-10 출원연도 (10/11, 채택 안 함)**: +0.006이지만 상표 자체 정보가 아니고 최근 연도는 심사 중 상표가 빠져 왜곡될 수 있다.
- **B-11 지정상품과 상표명의 관계 (10/11)**: 이름 속 상품명이 "내 상품"이면 식별력 문제, "남의 상품"이면 품질오인 문제라 비중을 나눠 넣었다. 자기 상품명이 들어간 상표 거절률 33.3%(없음 20.0%).
- **B-12 결합상표 단어별 비교 (10/11)**: 심사의 분리관찰처럼 "할매손 김밥"을 단어로 나눠 비교했다. 단어 희소성을 미래 상표까지 포함해 계산한 실수(0.697로 부풀려짐)를 발견해 고쳤다. 0.682 → 0.692.
- **B-13 유사 판단을 주요부 기준으로 통일 (10/11)**: "할매손김밥"이 "한끼김밥"과 0.72로 비슷하게 나왔다. 공통 글자 "김밥" 때문이다. 전체 이름 기준 변수를 빼도 점수가 그대로여서(0.692 → 0.691) 심사 방식에 맞게 모두 주요부 기준으로 바꿨다. "할매손 vs 한끼" 0.46.
- **B-14 주요부 추출 순서 고정 (10/11)**: 길이가 같은 단어의 삭제 순서가 실행마다 달라져 가나다·알파벳 순으로 고정했다(Python·JavaScript 모두).
- **B-15 단어별 거절률 (10/12~13)**: 예환 모델이 더 높았던 이유를 분해해 보니 2글자 조각별 과거 거절률의 몫이 가장 컸다. 다만 예환 방식은 나중에 출원된 상표의 결과도 들어간다. 각 상표보다 먼저 출원된 상표만으로 다시 계산하고, 표본이 적은 조각은 전체 거절률 쪽으로 당겼다. 5-fold 0.694 → 0.704, 2023~24 0.713 → 0.723. 교차검증의 +0.019 중 약 절반이 미래 정보 몫이었다.

## C. 모델

- **C-1 평가 지표를 ROC-AUC로 (10/6)**: 임의의 기준값으로 재현율·정밀도를 재는 대신, 기준값 없이 순서를 잘 세우는지 보는 ROC-AUC(주)·PR-AUC·Brier로 비교한다. 재현율·정밀도는 등급 선을 정할 때만 쓴다.
- **C-2 같은 출원인 + 같은 상표명은 같은 fold로 (10/6)**: 같은 이름을 여러 류로 내면 답이 새어 나가서 StratifiedGroupKFold로 묶었다.
- **C-3 모델 교체 (10/9~10, 채택 안 함)**: 로지스틱·나무·AdaBoost·XGB·LightGBM 모두 0.630~0.652. 모델이 아니라 변수가 한계라고 보고 변수·데이터 개선으로 방향을 바꿨다.
- **C-4 하이퍼파라미터 조정 (10/11, 채택 안 함)**: 내부 검증에서 좋아 보였지만 5-fold로 다시 재니 차이가 없었다. 기본 설정을 유지했다.
- **C-5 위험 등급 선 (10/11)**: 1차 점검 도구는 위험한 상표를 놓치지 않는 게 중요하다. "낮음"에서 놓치는 거절이 5% 안팎이 되도록 12%·30% 선을 정했다.
- **C-6 같은 상표가 있는데 100%가 아닌 이유 → 법적 경고 (10/11)**: 타인 동일 주요부 상표가 있어도 실제 거절률은 36.2%였다. 지정상품 삭제 보정·선권리자 동의·불사용 취소처럼 심사 중 대응해 등록된 경우가 "등록" 라벨에 섞인 것으로 본다(추정). 확률만 보면 위험이 과소평가되므로 이런 경우 상표법 제34조①7호 경고를 띄우고 등급을 고정했다.
- **C-7 XGB 비교 (10/12, 채택 안 함)**: 같은 28변수로 XGB 0.696 vs RF 0.694. 차이가 fold 편차보다 작고, RF가 "낮음"에서 놓치는 거절이 더 적었다.
- **C-8 거절 유형 보조 모델 (10/12)**: 간이 규칙은 적중률 20.0%였다. "거절된다면 왜인가"를 묻는 모델이므로 거절 상표만으로 학습하고, "복합"은 유사·식별력이 겹친 경우라 두 질문에 각각 답하는 RF 2개로 만들었다. 46.3%(최빈 유형만 찍기 39.2%).
- **C-9 세 모델을 같은 기준으로 재계산 (10/12)**: 같은 행·같은 fold로 다시 계산해 각자 적은 점수를 소수 셋째 자리까지 재현했다. 해인 RF 0.694 / 예환 XGB 0.725 / 가은 XGB 0.654.
- **C-10 시간 분할 검증 (10/12~13)**: 교차검증만으로는 미래 정보로 부풀려진 몫과 진짜 실력을 가를 수 없다. 2022년까지로 학습하고 2023~24 출원 65,590건을 예측했다. 해인 RF + 단어별 거절률 0.723 / 예환 0.721, 차이 −0.002 [−0.006, +0.002]로 통계적 차이 없음.
- **C-11 최종 모델 확정 (10/13)**: RF와 XGB(32변수)는 ±0.003 차이로 사실상 같았다. 새 데이터 성적이 조금 더 높고, 출원인 정보 없이 점검기 입력만으로 계산되는 **RF + 단어별 거절률**로 확정했다.
- **C-12 위험 등급 4단계 (10/17)**: "높음" 실제 거절률 42.9%가 낮아 보였지만, 비교 대상은 100%가 아니라 평균 23.6%다. 선을 올리면 많이 잡는 능력을 잃어서 30% 선은 두고 그 위를 한 번 더 나눴다. 50%는 새 데이터에서 56.2%로 흔들려 60%로 정했다. 매우 높음 68.0%(2023~24 68.1%).

## D. 점검기

- **D-1 새 상표를 직접 입력 (10/11)**: 현존 상표 57만 건·사전·경량 모델을 페이지에 넣고 변수 계산을 JavaScript로 옮겼다. 류 대신 지정상품을 고르면 유사군코드로 바뀌게 했다. 출원인 데이터는 넣지 않고 "내 상표"를 누르면 본인 상표로 다시 계산한다.
- **D-2 근거 상표와 목록 맞추기 (10/11)**: 근거로 센 상표를 목록 맨 위에 두고 "주요부 동일·포함·같은 단어·음역 유사" 표시를 붙였다.
- **D-3 거절 유형은 "참고"로 (10/12)**: 적중률이 50%에 못 미쳐 확정 진단처럼 보이지 않게 했다.
- **D-4 최종 모델로 교체 (10/13)**: 새 상표에게는 학습 상표 전체가 "먼저 출원된 상표"이므로 조각별 표만 있으면 브라우저에서도 같은 단어별 거절률을 낸다. 32변수 경량 RF로 바꿨다(0.692 → 0.702).
- **D-5 4단계 등급 반영 (10/17)**: 60% 눈금을 넣고 법적 경고 시 고정 등급을 "매우 높음"으로 바꿨다.
