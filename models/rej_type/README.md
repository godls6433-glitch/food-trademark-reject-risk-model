# 예상 거절 유형 보조 모델 (2026-10-12)

## 방식
- 대상: 학습 라벨 거절 건 중 거절 사유가 매칭된 16,834건 (유사 6,598 / 복합 5,756 / 식별력 4,480). 지정상품만 90건은 유사·식별력 어느 쪽도 아니어서 제외
- 다중 라벨: 유사 = {유사, 복합}, 식별력 = {식별력, 복합}. 이진 모델 두 개를 따로 학습
- 출력 규칙: 두 확률이 모두 기준 이상이면 "복합(유사+식별력)", 아니면 기준보다 더 높은 쪽 하나
- 입력: features_final_v8.csv 28변수 그대로 (거절 확률 모델과 동일), fold 컬럼 그대로
- 튜닝: 바깥 fold마다 남은 4개 fold로 안쪽 CV, 설정은 두 라벨 ROC-AUC 합, 기준값은 3유형 macro F1로 학습 fold 안에서만 선택. random_state=42
- 이 모델은 "거절된다면 어떤 유형일지"를 고르는 조건부 모델. 거절 확률은 기존 RF가 담당

## 결과 (5-fold OOF, 16,834건)
| 방법 | 3유형 정확도 | macro F1 | 유사 AUC | 식별력 AUC |
|---|---|---|---|---|
| 지금 점검기 간이 규칙 | 20.0% (절반은 "유형 없음") | 0.261 | – | – |
| 전부 "유사" | 39.2% | 0.188 | – | – |
| 로지스틱 | 44.3% | 0.443 | 0.684 | 0.631 |
| LightGBM | 46.1% | 0.462 | 0.705 | 0.649 |
| **랜덤포레스트 (채택)** | **46.3%** | **0.463** | **0.705** | **0.648** |

- fold별 정확도 RF 45.8~47.1%, 안정적
- 간이 규칙은 유형을 낸 8,443건만 봐도 40.0% 일치
- 유형별 F1(RF): 유사 0.50 / 식별력 0.47 / 복합 0.42. 복합과 유사 사이 혼동이 가장 큼
- 채택 이유: LightGBM과 차이 없음, 팀 주력 모델이 RF라 설명이 쉬움

## 최종 모델
- rej_type_rf.joblib: RF 300그루, min_samples_leaf 20, max_features sqrt, class_weight balanced (5-fold 중 3번 선택된 설정), 기준값 유사 0.425 / 식별력 0.475
- 중요 변수: 유사 쪽 tok_max_idf·logo·도형복합·core_sim, 식별력 쪽 core_translit_sim·core_sim·desc_ratio2 (feature_importance.csv)

## 한계
- 사유 매칭률이 연도별로 다름(2020~2022 약 15%, 2023~2024 약 50~60%). 최근 출원 비중이 큼
- 정확도 46%는 3지선다 기준. 점검기에는 "참고" 표시 유지 권장
