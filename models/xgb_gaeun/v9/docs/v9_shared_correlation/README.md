# V9 공통 입력 변수의 상관관계와 축소 후보

2017–2021년 출원 중 V9의 실제 fit 행 148,646건을 분석했다. 연도별 건수는 25,611 / 25,933 / 28,302 / 33,176 / 35,624건이다. 예측 라벨과 2022년 이후의 변수값은 상관 계산에 사용하지 않았다.

V6 텍스트 캐시에서 V9가 선택한 기본 변수 11개와 문맥 변수 10개를 복원하고, V9 학습 특징 파일의 선행상표 검색 변수 32개를 출원번호로 맞췄다. 코호트와 검색 특징 파일의 SHA-256, 행 순서, 건수, 유한값 여부를 검증했다. 검색 변수는 학습 코드와 동일하게 float32로 변환했다.

## 우선 검증할 48변수 모형

- 학습 전체에서 0인 kb_EFFECT_context, kb_USE_context, kb_PRICE_context, kb_COMMON_EXPRESSION_context를 제외한다.
- v7_pair_exact_goods를 제외하고 prior_exact_name_goods_coverage를 유지한다. 148,646건 전체에서 값이 같았으며, 두 열 모두 3,700건에서 0보다 컸다.
- 5개를 줄이면 공통 입력은 48개, XGBoost 입력은 텍스트 압축 64차원을 포함해 112개다. 변수 수 변경은 트리의 열 샘플링과 로지스틱 회귀의 정규화에 영향을 줄 수 있어 재학습 성능을 확인해야 한다.

## 추가 후보

상수가 아닌 변수 쌍에서 Pearson과 Spearman 절댓값이 모두 0.95 이상인 쌍은 완전 중복 포함 5쌍이었다. 아래 4쌍은 실제 값이 달라서 48변수 모형을 기준으로 한 번에 하나씩 제외할 후보다.

| 제외 시험 후보 | 유지할 비교 변수 | Pearson | Spearman | 검토 근거 |
|---|---|---:|---:|---|
| v7_char_max | prior_char_max | 0.99969 | 0.99997 | 문자 유사도 최댓값의 순서가 거의 같다. 54,510행에서 값이 달랐다. |
| v7_pair_char | prior_joint_combined_max | 0.98884 | 0.98287 | 문자·상품 결합 점수 간 중복이 크다. |
| latin_ratio | hangul_ratio | −0.98179 | −0.97839 | 숫자·기타 문자가 포함되면 두 비율은 서로의 여집합이 아니다. 혼합 표기에서 영향 확인이 필요하다. |
| v7_pair_top3 | v7_pair_best | 0.95622 | 0.97755 | 상위 후보 여러 건의 점수는 최고점이 같은 출원을 구분할 수 있어 후순위로 둔다. |

문맥 품질 변수 kb_QUALITY_context는 16건, 산지 변수 kb_LOCATION_context는 86건에서 작동했다. 드물다는 사실만으로 제외 후보에 넣지 않았다.

## 파일과 재현 방법

- pairs.csv에는 53개 변수의 모든 비순서 쌍 1,378개에 대한 두 상관계수와 값이 다른 행 수가 있다. 상수열과의 상관은 정의되지 않아 빈칸이다.
- feature_summary.csv에는 변수별 고유값 수, 0이 아닌 행 수, 최솟값, 최댓값이 있다.
- Python 3.11 이상과 NumPy, pandas, SciPy, PyArrow가 설치된 환경에서 아래 명령을 실행한다. 첫 번째 인수는 원본 trademark_risk_v6와 trademark_risk_v9 폴더의 공통 상위 경로다.

```shell
python analyze.py /path/to/version-directories /path/to/output
```

다음 실험은 원래 53개 모형과 우선 후보 5개를 뺀 모형을 같은 조건으로 학습하고, 2022년 보정 후 2023년 ROC-AUC·PR-AUC·Brier를 비교한다. 이 분석에서 모델 재학습은 수행하지 않았다.
