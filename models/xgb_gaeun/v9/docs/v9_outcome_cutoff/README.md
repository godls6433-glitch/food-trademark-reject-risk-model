# 47변수 V9의 결과 시점 점검과 발송일 기준 보조 실험

엄격한 기준은 2022년 12월 31일까지 제삼자가 거절·등록 결과를 알 수 있었음을 입증하는 것이다. 확인한 팀 풀과 원본 추출물에서는 거절결정서 발송일은 확보했으나 해당 거절 결과의 최초 공개일·배포일은 확인하지 못했다. 따라서 이 실험의 수치는 등록공고 연도·거절결정서 발송일 기준의 민감도 분석이다.

## 원자료와 채택 조건

- 팀 CSV 3개와 원본 데이터 폴더의 KIPRIS 엑셀 39개의 머리글에 등록일자, 출원공고일자, 등록공고번호가 있다. 출원공고 사실만으로 등록 결과를 확정하지 않았다. 등록·소멸 행 중 등록번호가 있고 등록일이 출원일 이후이면서 기준일 이하이고, 등록공고번호에 기재된 연도가 등록연도 이상이며 2022년 이하인 99,688건을 사용했다. 로컬 공식 서지에서 등록공고번호와 공고일을 함께 읽을 수 있는 11건의 연도 표기는 서로 일치했다. 날짜 단위의 등록공고일을 전수 복원한 것은 아니다.
- reject_reasons.csv의 17,310개 출원에는 거절결정서 발송일이 있다. 이 중 팀의 2017~22년 거절 행에 연결되는 건은 9,536건이다. 발송일이 출원일 이후이고 기준일까지인 7,615건을 보조 실험에서 사용했다. 1,921건은 기준일 이후이고, 팀 거절 행 중 37,844건은 이 파일에서 발송일을 입증할 수 없었다. 거절 사유와 날짜는 모델 입력에서 제외했다. 보유 공보 샘플 TB_KT10.txt의 32행 중 팀 자료와 출원번호가 일치한 2행에서도 거절결과의 과거 공개 근거를 얻지 못했다.
- KIPRISPlus는 거절결정서를 출원인에게 거절을 통보하는 발송 서류로 설명한다. 공개 데이터 상품의 현재 제공 사실만으로 개별 문서의 과거 최초 공개일을 정할 수 없다. [공공데이터포털 상품 설명](https://www.data.go.kr/data/15046711/fileData.do)

## 학습과 비교

| 모델 | 학습·보정 대상 | 거절률 | ROC-AUC | PR-AUC | Brier | 평균 예측 거절 확률 |
|---|---:|---:|---:|---:|---:|---:|
| 기존 47변수 V9 | 191,810 | 24.70% | 0.71992 | 0.40695 | 0.14688 | 25.54% |
| 등록공고·거절 발송일 기준 | 107,303 | 7.10% | 0.66322 | 0.31788 | 0.17360 | 6.73% |

두 모델 모두 같은 2023~24년 65,590건(거절 13,262건, 20.22%)에서 평가했다. 기존 47변수 설정과 팀 fold, 2022년 말 고정 검색 특징을 유지했다. 각 fold의 TF-IDF·SVD, 두 모델 및 OOF 보정기를 선별된 학습 행만으로 다시 적합했다. 평가 라벨은 채점에만 사용했다. 학습 표본 크기, 연도별 구성, 거절 자료 확보율과 보정 기준률이 함께 달라져 성능 차이에서 시간 누수만의 효과를 분리할 수 없다.

## 재현

기존 연구 버전 폴더의 공통 상위 경로에서 실행한다. CACHE는 팀 시간 분할 실험에서 만든 v9_team_holdout/artifacts, PREVIOUS는 v9_team_reduced/artifacts 디렉터리다.

```sh
exp=food-trademark-reject-risk-model/models/xgb_gaeun/v9/docs/v9_outcome_cutoff
mkdir -p "$exp/artifacts"
python "$exp/cohort.py" "$CACHE"
python "$exp/fit.py" "$CACHE" --shard 0
python "$exp/fit.py" "$CACHE" --shard 1
python "$exp/evaluate.py" "$CACHE" "$PREVIOUS"
```

cohort.py는 날짜 근거와 포함 여부를 대조한다. fit.py는 학습 부분별 모델을 만들며 evaluate.py는 OOF 보정과 평가를 수행한다. metrics.csv에는 전체 및 연도별 결과가 있다.
