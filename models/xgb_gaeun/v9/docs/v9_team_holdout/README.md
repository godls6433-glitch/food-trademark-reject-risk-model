# 팀 시간 분할에서 가은 XGB 219변수와 V9 비교

팀의 label_folds 기준으로 등록·공고·소멸은 0, 거절은 1로 통일했다. 동일한 순번과 출원번호를 사용하며 여러 상품류 행이나 기간 간 이름 중복을 V9 고유 규칙으로 제거하지 않았다. 2017–2022년 191,810건은 학습·보정에, 2023–2024년 65,590건은 최종 비교에 사용했다.

## 결과

| 기간 | 모델 | 건수 | ROC-AUC | PR-AUC | Brier |
|---|---|---:|---:|---:|---:|
| 2023–24 | xgb219 | 65,590 | 0.66375 | 0.34664 | 0.15280 |
| 2023–24 | v9 | 65,590 | 0.71990 | 0.40696 | 0.14686 |
| 2023 | xgb219 | 33,070 | 0.66516 | 0.36122 | 0.15604 |
| 2023 | v9 | 33,070 | 0.72591 | 0.42961 | 0.14793 |
| 2024 | xgb219 | 32,520 | 0.66222 | 0.33176 | 0.14952 |
| 2024 | v9 | 32,520 | 0.71473 | 0.38489 | 0.14577 |

전체 실제 거절률은 20.22%였다. 평균 예측 거절 확률은 219변수 모델 24.04%, V9 25.52%였다. V9의 순위 구분력과 Brier는 개선됐지만 평균적으로 거절률을 높게 추정했다.

## 실험 조건

- V9 변수 축소 전 모델을 사용했다. XGBoost에는 SVD 64차원과 공통 변수 53개, 로지스틱 회귀에는 문자·자모·지정상품 TF-IDF와 공통 변수 53개를 넣었다. 기존 V9 설정으로 학습한 두 갈래의 점수를 0.5씩 혼합했다.
- 219변수 제출본과 동일하게 2022년까지의 팀 지정 5-fold에서 각 행의 out-of-fold 혼합 예측을 만들고 sigmoid 보정기를 맞췄다. 최종 두 갈래는 191,810건 전부로 재학습했다. TF-IDF 어휘·IDF와 SVD도 각 fold의 학습 부분 및 전체 재학습에서 각각 다시 적합했다.
- 학습 출원은 출원일보다 이른 출원·공고만 검색한다. 2023–24년 질의에는 출원일과 공고일 모두 2022년 12월 31일 이하인 후보만 허용했다. V9에서 보완한 공고일과 V9의 가족 사건 제외 규칙을 유지했다. 학습 중 원본 질의 입력이 모두 같은 173,443건은 시점 조건이 같은 V9 검색 특징을 재사용하고, 나머지 83,957건은 다시 계산했다.
- 219변수 모델과 V9가 쓰는 입력 정보는 다르다. V9는 지정상품 문장과 근거를 확인한 공고일도 쓴다. 따라서 전체 예측 방식 간 비교이며 알고리즘 단독 효과를 분리하는 실험은 아니다.
- 팀 행을 모두 유지하기 위해 정규화 후 상표명이 빈 12건(평가 2건)은 이름 텍스트를 빈 값으로 두고 검색 후보 없음으로 처리했다. 명칭구분이 비어 있는 13건은 로고 0으로 처리했다.
- V9 설계 당시 일부 2023–24년 자료를 이미 개발·비교에 사용했다. 현재 실험은 기존 팀 자료의 사후 비교이며 새 맹검 평가가 아니다. 검색 후보 시점은 기록된 출원·공고일 기준이며, 과거 지정상품 변경이나 라벨 확정 시점까지 재현하지는 못한다.

## 재현

원래 버전 폴더와 로컬 클론이 있는 공통 상위 경로에서 다음 순서로 실행한다. Python 3.12, pandas, NumPy, PyArrow, SciPy, scikit-learn, XGBoost, joblib, RapidFuzz 및 기존 로컬 원자료·색인이 필요하다. 중간 결과와 예측은 이 실험의 artifacts 폴더에 저장한다. 새로운 자료로 실행할 때는 비어 있는 artifacts 폴더를 사용한다.

```sh
experiment=food-trademark-reject-risk-model/models/xgb_gaeun/v9/docs/v9_team_holdout
mkdir -p "$experiment/artifacts"
python "$experiment/prepare.py"
python "$experiment/search.py"
python "$experiment/text_input.py"
python "$experiment/vectorize.py"
python "$experiment/fit.py"
python "$experiment/evaluate.py"
```

metrics.csv는 전체 및 연도별 ROC-AUC, PR-AUC(average precision), Brier, 평균 예측 확률을 담는다. paired_predictions.parquet에는 같은 행의 팀 라벨과 두 확률을 저장한다. 제출 예측 CSV의 순번·출원번호·fold, 원본 label_folds의 거절 정답, 팀 보관 지표 3종을 검증한다.
