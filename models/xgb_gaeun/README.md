# 가은의 식음료 상표 거절 위험 모델

식음료 상표의 출원 정보를 바탕으로 거절 가능성을 예측하는 두 모델을 담았습니다. **219변수 XGBoost**는 팀 비교에 제출한 모델이고, **V9**는 팀 최종 모델 선정 후 개발한 후속 모델입니다.

| 모델 | 예측 방식 | 코드와 설명 |
|---|---|---|
| 팀 제출 · 219변수 XGBoost | 상표명에 특정 단어가 있는지, 같은 상품류의 과거 상표와 이름이 얼마나 비슷한지 등을 219개 변수로 계산합니다. | [모델 설명과 실행 방법](original_xgb_219/README.md) · [소스 코드](original_xgb_219/src/) |
| 후속 연구 · V9 | 먼저 출원·공고된 상표별로 이름·발음의 유사도와 지정상품의 겹침을 계산합니다. 이를 활용하는 XGBoost와 상표명·지정상품의 문자 패턴을 학습하는 로지스틱 회귀의 예측을 평균합니다. | [모델 구조와 실행 방법](v9/README.md) · [원본 V9 코드](v9/src/trademark_risk/) · [47변수 학습 코드](v9/docs/v9_final_rf_protocol/train.py) |

## 팀 데이터 평가 결과

| 모델 | 5-fold ROC-AUC ↑ | 5-fold PR-AUC ↑ | 5-fold Brier ↓ | 2023~24년 ROC-AUC ↑ |
|---|---:|---:|---:|---:|
| 기존 219변수 XGBoost | 0.6543 | 0.3742 | 0.1695 | 0.6637 |
| 후속 V9 · 공통 변수 47개 | **0.7141** | **0.4453** | **0.1598** | **0.7199** |

**5-fold 평가**에서는 팀 공통 257,400건을 같은 다섯 그룹으로 나눴습니다. 219변수 모델은 내부 교차검증 예측으로 sigmoid 보정을 했습니다. V9의 0.7141은 팀 최종 RF와 같이 매번 평가 그룹을 제외한 자료의 약 80%로 학습하고, 20%로 isotonic 보정을 한 결과입니다. [팀 제출 모델 평가](../../evaluation/README.md) · [V9의 최종 RF 방식 평가](v9/docs/v9_final_rf_protocol/README.md)

**시간 분할 평가**에서는 두 모델 모두 2022년까지의 출원으로 학습하고 같은 2023~2024년 출원 65,590건에서 평가했습니다. 학습 기간 내부의 5-fold 예측으로 확률을 보정했습니다. 출원일을 기준으로 분할했으며, 당시 모든 학습 건의 결과가 공개됐는지는 확인하지 못했습니다. [시간 분할 조건](v9/docs/v9_team_holdout/README.md) · [47변수 결과](v9/docs/v9_team_reduced/metrics.csv)

## V9에서 ‘47개’와 ‘111개’의 의미

두 모델은 출원 한 건에서 계산한 **기본 정보 11개, 사전 문맥 6개, 선행상표 검색 변수 30개**를 함께 사용합니다. 이 47개에 XGBoost는 텍스트 압축값 64개를 더해 **총 111개**를 입력받습니다. 로지스틱 회귀는 같은 47개에 압축 전 텍스트 특징을 더합니다. 원본 V9는 공통 변수 53개를 사용했고, 위 표는 이를 47개로 줄여 재학습한 결과입니다. [입력 구성 도식](v9/README.md#47변수-v9의-입력-구성과-예측-과정) · [변수 축소 실험](v9/docs/v9_team_reduced/README.md)
