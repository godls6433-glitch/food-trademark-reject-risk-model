# 팀 프로젝트 진행 이력

세 명이 같은 데이터·라벨·fold 위에서 각자 다른 방식으로 모델을 만들고, 같은 기준으로 비교한 뒤 장점을 합쳐 최종 모델을 정했습니다. 이 문서는 팀 전체의 흐름이고, 모델별 세부 이력은 각 모델 폴더에 있습니다([해인 RF](../models/rf_haein/process.md)).

## 1. 진행 순서

| 날짜 | 단계 | 내용 |
|---|---|---|
| 10/4 | 데이터 수집 | KIPRIS에서 29·30·32·43류 2017.1~2026.9 출원 395,982건 수집. 비교 대상이 "먼저 출원된 상표"이므로 모든 데이터를 등록일이 아닌 출원일 기준으로 받기로 함 |
| 10/6 | 고정 기준 | 라벨(결과 확정 2017~2024 출원 257,400건, 등록·공고·소멸 = 1, 거절 = 0), 제외 대상, 평가 지표(ROC-AUC 주, PR-AUC, Brier), fold 방식 확정 |
| 10/6~8 | 비교용 데이터 추가 | 2016년 이전 현존 상표 141,494건, 2005~2016 소멸 상표 93,292건 |
| 10/8 | 팀 공통 규칙 | "통일할 것"과 "각자 정할 것"을 나눔 (2장) |
| 10/9~11 | 각자 모델 개발 | 해인 RF, 예환 XGB, 가은 XGB를 각자 방식으로 개발하고 예측값 파일(257,400행)과 설명서 제출 (3장) |
| 10/12 | 같은 기준 재계산 | 세 예측값을 같은 라벨·같은 fold로 다시 계산해 비교, 차이가 어디서 오는지 분해 (4장) |
| 10/12~13 | 시간 분할 시험 | 2022년까지로 학습하고 2023~24 출원 65,590건을 예측. 세 명 모두 같은 방식으로 예측값을 다시 냄 |
| 10/13 | 최종 모델 확정 | 해인 RF 구조 + 예환의 단어별 거절률(누수 없게 고친 버전), 32변수 (5장) |
| 10/12~13 | 보조 기능 | 거절 유형 보조 모델, 점검기 최종 모델 반영 |
| 10/17 | 등급·공개 기준 | 위험 등급 4단계(12%·30%·60%) 확정. KIPRIS 약관 제16조 때문에 원자료 대신 예시 30줄만 공개하기로 결정 |

## 2. 팀 공통 규칙 (10/8)

모델이 달라도 결과를 나란히 비교할 수 있도록 아래만 통일하고, 나머지는 각자 정했습니다.

| 통일한 것 | 각자 정한 것 |
|---|---|
| 데이터(학습용 풀·현존·소멸 상표), 다른 데이터를 쓰면 팀에 알리기 | 알고리즘, 하이퍼파라미터 |
| 라벨 257,400행 고정, 거절 사유는 입력 변수로 쓰지 않음 | 비교 대상(같은 류 / 4개 류 / 유사군코드), 본인 상표 처리 |
| 출원일 이후 정보 사용 금지 | 변수, 사전, 상표명 정규화 |
| 고정 fold(같은 출원인 + 같은 상표명 한 그룹), 튜닝은 학습 fold 안에서만 | 불균형 처리, 확률 보정 방식 |
| 지표: ROC-AUC(주)·PR-AUC·Brier, random_state 42 | |
| 제출물: 예측값 파일(순번·출원번호·fold·거절확률) + 모델 설명서 | |

이렇게 나눈 이유: 같은 문제를 서로 다른 관점으로 풀어 보되, 점수는 같은 잣대로 비교할 수 있어야 누구 방식이 왜 좋은지 가를 수 있기 때문입니다.

## 3. 세 모델의 접근

| | 해인 RF | 예환 XGB | 가은 XGB |
|---|---|---|---|
| 알고리즘 | 랜덤포레스트 300그루 | XGBoost 600그루, depth 6 | XGBoost 600그루, depth 6 |
| 변수 수 | 28 | 54 | 219 |
| 비교 대상 | 유사군코드 겹침, 다른 류(5·31·33·1류) 추가, 750,680건 | 4개 류로 좁힌 뒤 유사군코드 겹침, 630,768건 | 4개 류 겹침, 630,768건 |
| 본인 상표 | 출원인 판별 규칙 5개로 본인·계열사 제외 | 같은 고객번호 제외 | 비교에 포함 |
| 유사 판단 | 주요부(설명어를 뺀 부분) 기준 발음·음역·포함 유사도 | 핵심부분 일치, 자모 유사도 | 문자 조각 검색 상위 5개 유사도 |
| 특징적인 변수 | 본인 상표 유사도, 영문 설명어 사전, 지정상품-상표명 관계 | 단어·2음절 조각별 과거 거절률, 출원인 이력 | 단어 포함 여부 164개, 사전 요약 12개 |
| 확률 보정 | isotonic | 사용 안 함 | sigmoid |
| 5-fold ROC-AUC | 0.694 | **0.725** | 0.654 |

각자 설명서 수치는 재계산에서 소수 셋째 자리까지 같게 재현됐습니다. 세 모델 예측의 순위 상관은 0.51~0.61로, 서로 꽤 다른 신호를 쓰고 있었습니다.

## 4. 비교에서 나온 판단 (10/12~13)

- **예환 모델이 높은 이유**: 변수를 하나씩 더해 보니 단어(2글자 조각)별 과거 거절률의 몫이 가장 컸고(+0.019), 출원인 경험이 다음이었습니다.
- **그대로 가져올 수 없던 이유**: 예환 방식의 단어별 거절률은 학습 fold 전체로 계산해, 대상 상표보다 나중에 출원된 상표의 결과도 들어갑니다. 실제 점검기를 쓸 때는 없는 정보입니다. 출원인 경험은 심사 과정과 관계가 없고 점검기 입력(상표명·지정상품·로고)으로 계산할 수 없습니다.
- **가은 모델이 낮은 이유**: 류 단위로 비교하고 본인 상표를 빼지 않아, 출원을 많이 한 출원인일수록 위험을 과하게 잡았습니다(실제 14.6%, 평균 예측 22.0%).
- **시간 분할로 확인**: 교차검증 점수만으로는 미래 정보로 부풀려진 몫과 진짜 실력을 가를 수 없어서, 실제 쓰임과 같은 "과거로 학습, 미래를 예측" 시험을 했습니다.

| 2023~24 새 데이터 | ROC-AUC |
|---|---|
| 해인 RF + 단어별 거절률(먼저 출원만) | **0.723** |
| 예환 XGB | 0.721 |
| 해인 RF | 0.713 |
| 가은 XGB | 0.664 |

교차검증에서 0.031이던 예환 모델의 우위는 새 데이터에서 0.008로 줄었고, 단어별 거절률을 누수 없이 고쳐 해인 RF에 더하자 차이가 −0.002 [−0.006, +0.002]로 통계적으로 같아졌습니다. 출원인 경험은 새 데이터에서 효과가 없었습니다(0.713 → 0.713).

## 5. 최종 결정 (10/13)

**해인 RF + 단어별 과거 거절률(먼저 출원된 상표만), 32변수.**

| 가져온 것 | 출처 | 이유 |
|---|---|---|
| 비교 대상·본인 상표 제외·주요부 유사도 | 해인 RF | 실제 심사 방식(유사군코드, 타인 상표, 요부 관찰)과 맞음 |
| 단어별 과거 거절률 | 예환 XGB | 가장 큰 효과. 먼저 출원된 상표만으로 다시 계산해 누수 제거 (+0.010이 교차검증·새 데이터 모두 유지) |
| 출원인 경험 | 예환 XGB | **채택 안 함**. 새 데이터에서 효과 없고 점검기 입력으로 계산 불가 |
| 단어 포함 여부·사전 요약 | 가은 XGB | **채택 안 함**. 류 단위 비교의 한계가 더 컸음 |

같은 32변수로 XGB도 만들어 봤지만 RF와 ±0.003 차이로 사실상 같아서, 새 데이터 성적이 조금 더 높고 점검기에 바로 반영할 수 있는 RF를 골랐습니다. 교차검증 1등을 그대로 고르지 않고, 점수가 어디서 왔는지 분해하고 미래 데이터로 검증한 뒤 각 모델의 장점을 합친 것이 이 프로젝트의 핵심 판단입니다.

## 6. 이후 공통 작업

- **위험 등급 (10/11 → 10/17)**: 처음 3단계(12%·30%)에서, "높음" 실제 거절률 42.9%가 낮아 보인다는 문제로 30% 위를 한 번 더 나눠 4단계로. 50% 선은 새 데이터에서 56.2%로 흔들려 60%로 정함(매우 높음 68.0%, 새 데이터 68.1%).
- **법적 경고**: 타인 동일 주요부 상표가 같은 유사군코드에 있으면 확률과 별개로 상표법 제34조①7호 경고를 띄우고 "매우 높음"으로 고정.
- **거절 유형 보조 모델**: 거절 상표만으로 유사·식별력 RF 2개를 학습. 적중률 46.3%(간이 규칙 20.0%).
- **데이터 공개**: KIPRIS 약관 제16조에 따라 원자료는 공개하지 않고 예시 30줄(출원인 익명 ID)만.
