상표 거절 위험 점검기 · 시연판

출원 전에 식음료 상표(29·30·32·43류)의 거절 위험을 점검하는 모델의 결과 예시예요. 아래 상표들은 실제 점검기 엔진으로 미리 계산한 결과이고, 같은 상표명을 로고 유무만 바꿔 비교할 수 있어요.

예시 상표

시연판에 대해

  • 실제 점검기는 KIPRIS 현존 상표 579,256건과 비교해요. 이 데이터는 KIPRIS 이용약관 제16조에 따라 공개할 수 없어서, 이 페이지에는 미리 계산한 예시 결과만 넣었어요.
  • 모델: 랜덤포레스트 경량판(나무 100개, 깊이 14), 변수 32개(기존 28개 + 단어별 과거 거절률 4개). 5-fold 교차검증 ROC-AUC 0.702 (전체 모델 0.704, 2022년까지 학습해 2023~2024년을 예측하면 0.723). 확률은 isotonic으로 보정했어요.
  • 위험 등급: 낮음 12% 미만 · 중간 12~30% · 높음 30~60% · 매우 높음 60% 이상. 등급별 실제 거절률은 8.8% · 20.0% · 39.4% · 68.0%예요 (전체 평균 23.6%). 주요부가 같은 타인의 등록·공고 상표가 같은 유사군코드에 있으면 매우 높음으로 보여줘요.
  • 예상 거절 유형은 보조 모델(랜덤포레스트 두 개, 유사·식별력)이 고른 참고값이에요. 세 유형 적중률은 46%예요.
  • 이 결과는 출원 전 1차 점검용이에요. 실제 등록 여부는 심사관 판단과 의견서·보정에 따라 달라질 수 있어요.
